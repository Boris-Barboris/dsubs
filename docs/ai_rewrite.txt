Current problems:

1). OrderQueue is ugly and unnecessary.
2). Unnecessary separation into 3 crew members and order queues between them. This can simply be done by Parallel control node in one BT. Strange stuff like order cooldowns. HelmsmanOrderGoal bullshit.
3). shouldBeRunning paradigm merges Condition and ActionNode into one non-configurable entity, reducing flexibility.
4). Blackboard state currently consists only of CIC contacts.
5). There is 1t1 relation between BT and bot difficulty.
6). Over-generalist AIs must be split into separate trees to handle different sub layouts and tactics. No need for an over-generalist AI.
7). Lot's of in-engine code that cannot be configured.
8). ReceiveHydrophoneData probably should not be a BT action in the first place, since it should always be executed. AddNewHydrophoneContact and ClassifyAndTrack are problematic as well, since they cannot be expressed in configuration. Although, per-tree tunable detection margins are good, as well as the inherent protection from perfect machine speed. These nodes make sure AI is overwhelmed by target-rich environments just as human. Perhaps friendly filtered-out imprints should also slow AI down?
9). Balance between parameter-tuning and hardcoded values must be struck. Example: engagement range, hardcoded vs calculated based on torpedo range.
10). How to handle multi-weapon bots that have different tactics based on weapons.
11). Bots that can handle multiple threats and multiple targets. Threat and target prioritization should be part of a blackboard?
12). Blackboard is unobservable.
13). Play sound node/action, when player feedback is needed.
14). Group AI is currently absent and cannot be incorporated.
15). There is no re-use between the AI trees, except the obvious sonar/hydrophone subtrees that probably should not be BTs in the first place.
16). Not sure how to implement cutscene logic in the current architecture.
17). Wildlife eating habits and general target/FoF filtering is unconfigurable.

evadeDangersSubtree:
    Sequence:
        Action: selectMainDanger(listOfDangers, 1500m)
        Condition: mainDanger != null
        Action:
            evadeCourse := maximizeTransversalFor(mainDanger, spdAtThrottle(100%))
        Action: swimRelativeToSelf(evadeCourse, 2000m, 100%)


// tree that accounts for multiple dangers and dodges away when no ammo and into the danger
// when has ammo
evadeDangersSubtree:
    Sequence:
        Action: dangersPrioritised := sortDangers(listOfDangers, 2500m, 5.0f)   // 5.0 is some factor that reduces weight of small or distant dangers
        Condition: dangersPrioritised.length > 0
        Fallback:
            Sequence:
                Condition: ammoCount("weapons") > 0
                Action: evadeCourse := course(
                    weightedEvadeCourse(dangersPrioritised, spdAtThrottle(100%)).normalized +
                    corseVector(dangersPrioritised[0]).normalized)
            // else
            Action: evadeCourse := course(
                    weightedEvadeCourse(dangersPrioritised, spdAtThrottle(100%)).normalized -
                    corseVector(dangersPrioritised[0]).normalized)
        Action: swimRelativeToSelfFor(evadeCourse, 2000m, 100%, 20s)    // maintain sprint for at least 20 seconds

let's write subtree that tackle weaponry of a two-weapon submarine, for example electra+tornado Lima.


weaponControlSubtree:
    Fallback:
        // load sequence
        Sequence:
            Condition: numberOfEmptyTubes("weapon") > 0
            Condition: ammoCount("weapons") > 0
            Action: loadWeaponsToTubes({"Tornado": 1, "Electra": 1})
        // launch sequence
        Sequence:
            Condition: mainTarget != null
            FallbackMem:
                // Tornado is priority
                SequenceMem:
                    Condition: numberOfLoadedWeapons("Tornado") > 0
                    Action: firingSolution = calcShooting(mainTarget, "Tornado", 100%)
                    Condition: firingSolution.exists && firingSolution.fuelBurned < 80%
                    Action: openTubeWithWeapon("Tornado")
                    Action: fireTubeWithWeapon("Tornado", firingSolution)
                    Sleep: 20s
                // fallback to Electra
                SequenceMem:
                    Condition: numberOfLoadedWeapons("Electra") > 0
                    Action: randomSensorMode = selectFromWeighted(
                        {"active": 3, "passive": 1})
                    Action: randomTorpSpd = randomFloat(electra.minSpd, electra.maxSpd)
                    Action: firingSolution = calcShooting(
                        mainTarget, "Electra", randomTorpSpd)
                    Condition: firingSolution.exists && firingSolution.fuelBurned < 75%
                    Action: openTubeWithWeapon("Electra")
                    Action: fireTubeWithWeapon("Electra", firingSolution)
                    Sleep: 20s  // some reasonable anti-spam cooldowns
